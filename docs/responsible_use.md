# Responsible Use

NEPAL is a research artifact for evaluating re-identification risks in privacy-preserving record linkage systems.
It demonstrates that similarity-preserving encodings can leak information when an attacker has known plaintext-encoding pairs.

Use this repository only for:

- reproducing the published experiments
- evaluating systems you own or are authorized to assess
- comparing defensive encodings and hardening strategies
- academic research, teaching, and peer review

Do not use this repository to identify people in datasets without authorization, to bypass privacy protections in operational systems, or to publish reconstructed identifiers from real individuals.

When using NEPAL on sensitive or non-public data:

- obtain explicit authorization before running attacks
- minimize and protect plaintext data, encodings, intermediate caches, and experiment outputs
- avoid sharing reconstructed identifiers or record-level predictions
- report vulnerabilities responsibly to system owners
- follow applicable institutional review, data protection, and disclosure requirements

The included datasets are intended for reproducibility and benchmarking. They should not be interpreted as permission to apply the attack to unrelated real-world data.
